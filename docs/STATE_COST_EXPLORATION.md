# Supplementary results: control, observation and state count

[Overview](../README.md) · [Scientific guide](SCIENTIFIC_CASE.md) · [Results index](CLAIM_LEDGER.md) · [Verification](VERIFICATION.md)

The main two-switch result relates control timing and prediction accuracy
to the minimum reusable model size. The results below examine related
questions under their own model, preparation and observation assumptions.
The results index gives each precise claim and its supporting evidence.
